# srezai skills 0.5.0

Шесть узких скиллов вместо одного большого: агент подключает только нужный канал
и читает только те references, которые нужны задаче.

- **srezai-web** — маршрутизация: какой канал выбрать (CLI, MCP, REST), установка,
  пробный режим без ключа, лимиты и коды ошибок.
- **srezai-search** — веб-поиск и подбор выдачи.
- **srezai-read** — чтение страниц и файлов, markdown, окна по offset.
- **srezai-site** — карта сайта и сбор раздела (map/crawl).
- **srezai-research** — deep research по тикету.
- **srezai-transcript** — расшифровка видео и аудио.

Стоимость контекста: типичная задача — около 0,9–1,7 тыс. токенов вместо
~10,8 тыс. у постоянного MCP-каталога; весь корпус шести скиллов — ~10,5 тыс.
против ~27,3 тыс. у аналога.

Установка:

```bash
npx skills add srezai-team/srezai-web-search-pro-skill
```

Компаньон — консольная обёртка `srezai-cli` (12 команд, без зависимостей):
`npm install -g srezai-cli`.

Полная документация: `llms.txt`, `docs/tools.md`, references внутри каждого скилла.
