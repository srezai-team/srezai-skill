# yt_srt — Текст ролика YouTube: субтитры, конспект, цитата

Цена: 1 кредит за ролик; 15 — с разметкой по спикерам · ≤5 роликов за вызов, окно по from/to, таймкоды, до 200 тыс. символов на ролик — длинный ролик приходит целиком. Платный.

## CLI

```bash
srezai transcript https://youtu.be/ID --languages ru --timestamps
```

## Параметры

videos (≤5), languages, timestamps, from, to, maxChars, speakers (разметка по говорящим)

## Когда не он

нужны видео с других площадок (VK, Rutube) — их нет; или нужен сам файл видео; для настоящего разделения по голосу speakers не подходит — это разметка по смыслу реплик

## Заметки

- `--speakers` — разметка по смыслу реплик, не диаризация по голосу
- только YouTube; VK/Rutube нет

## Вывод

results[]: текст/сегменты, credits, meta; слишком длинное — окно `--from`/`--to`

## Другие каналы

MCP: `yt_srt` · REST: `POST https://srezai.ru/api/v1/*` с Bearer-ключом.
