# Ошибки и восстановление

| Код | Что значит | Что делать |
|---|---|---|
| `401 unauthorized` | ключа нет, он отозван или неверен | проверить `srezai whoami`; получить ключ: `srezai register --email …` (новый email) или кабинет |
| `402 insufficient_funds` | не хватает кредитов | сказать человеку баланс и ссылку на пополнение; не повторять вызов |
| `403 forbidden` | лимит тарифа или закрытый инструмент | не обходить; предложить другой инструмент/тариф |
| `429 rate_limited` / `trial_limit_reached` | лимит по ключу или дневной триал (25/сутки на IP) | CLI сам делает до 3 попыток с `Retry-After`; вручную не зацикливать; подождать или взять ключ |
| `503 service_unavailable` | сервис временно недоступен | 3 попытки, затем сказать человеку и остановиться |
| `ssrf_blocked`, `host_unresolved` | адрес запрещён серверной защитой | не искать обход, взять другой источник |
| `schema_invalid` | схема извлечения не по формату | сокращённая схема: `{"title":"string","price":"number?"}`, `?` — необязательное, `[]` — массив |
| `bad_request` | параметры не те или не JSON | свериться со справкой команды `srezai <cmd> --help` |

## Принципы

- Не ретраить 401/402/403/400 — повтор не поможет.
- Не подменять инструмент молча: если srezai недоступен, сообщить человеку код и
  цифры (лимит, баланс), а не искать обходной путь.
- `verify_claim`: вердикты `unverified` и `mixed` — честный результат, а не сбой.
  Не переформулировать утверждение, пока не сказал об этом человеку.
- `deep_research`: синхронный вызов обрывается около 150-й секунды. Долгие темы —
  только `--async` и опрос по талону.
