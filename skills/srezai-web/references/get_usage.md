# get_usage — Баланс, остаток квоты, расход и прайс

Цена: бесплатно, квоту не расходует. Бесплатный.

## CLI

```bash
srezai whoami (локально: есть ли ключ и куда ходит)
```

## Параметры

verbose

## Когда не он

не нужен перед каждым вызовом

## Заметки

- бесплатный вызов, квоту не тратит
- в CLI 0.1 отдельной команды баланса нет

## Вывод

баланс/квота/прайс — через MCP `get_usage` или кабинет

## Другие каналы

MCP: `get_usage` · REST: `POST https://srezai.ru/api/v1/*` с Bearer-ключом.
