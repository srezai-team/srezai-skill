# deep_research — Многошаговое исследование темы с готовым ответом и источниками

Цена: 20 кредитов + 3 за каждую 1000 output-токенов · обычно 3–10 минут, до 42. Платный.

## CLI

```bash
srezai deep "тема" --async → srezai deep status <ticket>
```

## Параметры

query, ticket (дозабор готового ответа — бесплатно)

## Когда не он

нужен один факт или список ссылок — это web_search

## Заметки

- синхронный режим обрывается ~на 150-й секунде — для долгих тем только `--async`
- дозабор по талону бесплатный

## Вывод

async: талон 202; status: stage, progress, result, error

## Другие каналы

MCP: `deep_research` · REST: `POST https://srezai.ru/api/v1/*` с Bearer-ключом.
