# image_search — Картинки и прямые ссылки на файлы

Цена: 1 кредит за вызов · 1–48 картинок. Платный.

## CLI

```bash
srezai media "запрос" --num 3
```

## Параметры

query, num, timeRange, safe

## Когда не он

нужен текст страницы — это read_url

## Заметки

- проси `--num 1`–`3`, если нужна одна картинка: полный список съедает контекст

## Вывод

images[]: прямые ссылки и метаданные

## Другие каналы

MCP: `image_search` · REST: `POST https://srezai.ru/api/v1/*` с Bearer-ключом.
